# 事件影响与关联分析

每期最多六条金融重点。每条由事实摘录、事件分析、可能影响和后续观察组成。邮件末尾最多三组关联分析，以“第几条”指向本期事件；核验文件另存真实证据 ID，不在邮件中加入链接。

## 分析过程

1. 先通过新鲜度、主题和跨次历史检查，再选入事件。
2. 根据入选标题和实际展示的正文识别事件主题、变化方向、适用地区和事实阶段。旧事件的新增信息只分析新增正文，不借旧标题重新引入已发事实。
3. 解释经济传导渠道和成立条件。就业人数与失业率、能源产量与价格、海外汇款与汇率、债券期货价格与现券收益率分别处理。
4. 对具有共同主题或已定义传导关系的事件比较方向、地区和证据阶段；具体制裁与能源、科技合作的关联还需要对应行业线索。
5. 没有充分共同线索时明确不做关联；资料不足时不填补缺失数值，不声称已确认市场反应。

关系指向本期已经入选的事实，不把未入选消息或已发旧闻重新放入邮件。影响和关联文字不参与已发事实指纹，因此改写分析不会把旧事件变成新事件。规则不会尝试证明因果，也不会用多家转载当成独立事实验证。

## 范围与限制

默认实现是可检查的中文规则，不调用付费模型。它覆盖常见宏观和金融主题，不具备任意语言或任意事件的完整语义理解能力。预测与事实可能在同一篇报道中混杂，复杂表述仍需人工核对。行情变化也可能受未收录因素影响。少量来源或选择窗口不能代表全部市场信息。

目前不从历史邮件生成长期事件图谱；关联只使用本期通过去重的入选事实。正常时段没有新增重点时继续跳过邮件。

## 机制参考

规则中“政策利率、融资条件、需求和物价”的传导框架参考美联储的 [货币政策目标及运作](https://www.federalreserve.gov/monetarypolicy/monetary-policy-what-are-its-goals-how-does-it-work.htm) 与欧洲央行的 [货币政策传导机制](https://www.ecb.europa.eu/mopo/intro/transmission/html/index.en.html)。这些说明解释一般机制，不是对每期事件的因果验证。

## 验证

运行 `python -m unittest discover -p "test_*.py"`。测试覆盖预测与正式决定、涨跌方向、地区差异、错误行业关联、事实及去重历史不变，以及邮件发送保护。

预览 `run-status.json` 的 `analyzed_events` 应等于 `points`；`event_connections` 为实际成立的关联组数，可以为零。无新增时不会强行生成分析。
